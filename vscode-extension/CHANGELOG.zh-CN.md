# 更新日志

[English](./CHANGELOG.md)

**iris xml2udl** 插件的所有重要变更记录在此。

## 1.0.3 — 2026-09-20

- 修复：来自不同 XML 文件的同名组件不再共用一个虚拟文档页签 —— 文档身份现在包含来源文件
- 修复：修改 XML 内容后重新预览，会刷新已打开的 UDL 页签，不再显示旧内容
- 杂项：构建脚本移除硬编码的 Node.js 可执行文件路径，改用可移植的 `tsc` 调用

## 1.0.2 — 2026-06-18

- 新功能：Routine 使用 `type` 属性作为文件扩展名后缀（如 `websys.inc`、`websys.mac`）
- 文档：新增插件中文 README，与英文版互相链接
- 文档：为所有 README 补充安装说明
- 演示：界面支持中英文切换，支持 `?lang=zh|en` URL 参数（默认英文）
- 演示：本地打包 jQuery EasyUI 1.7.0，jQuery 改用 HTTPS 加载（消除混合内容警告）
- 演示：部署到 GitHub Pages，新增导航首页与自动部署流程

## 1.0.1 — 2026-06-12

- 文档：新增中英文 README，互相链接
- 文档：修正树视图说明 —— Class 成员是子项，不是顶层类型
- 杂项：修正 `package.json` 中的仓库地址
- 演示：页面资源指向线上地址

## 1.0.0 — 2026-06-09

- 首个版本
- 解析 IRIS XML 导出文件，按类型分组在树视图中展示组件
- 为 Class、Routine、CSP、Projection、UDLText 等组件类型生成 UDL 内容
- 预览页签行为与 VS Code 原生资源管理器一致（单击预览，双击固定）
- 基于文件扩展名的语言模式识别（.cls、.csp、.prj、.udl）
